CineTV

Proyecto de aplicación Android para explorar información de películas y series.

Acerca del proyecto

CineTV es una aplicación Android en desarrollo que organiza contenido por categorías y permite consultar información cinematográfica.

El proyecto busca integrar metadatos e imágenes de The Movie Database (TMDB) para mejorar la presentación de películas y series.

Proyecto CineTV

Esta aplicación no está avalada ni certificada por TMDB.
